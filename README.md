## Análise de Incidentes / MITRE ATT&CK

Cada incidente é analisado e mapeado às táticas e técnicas correspondentes
do MITRE ATT&CK, identificando como o ataque ocorreu e quais controles
poderiam ter mitigado cada etapa.

## Como usar este repositório

1. Navegue pelas pastas listadas em [Conteúdos](#conteúdos) para acessar as
   anotações de cada tema.
2. Cada estudo de caso ou incidente possui seu próprio arquivo `.md` com
   contexto, técnicas envolvidas (mapeadas ao MITRE ATT&CK quando aplicável)
   e principais aprendizados.
3. Sinta-se à vontade para abrir uma *issue* ou sugerir conteúdos — este é um
   repositório de estudos em constante evolução.
